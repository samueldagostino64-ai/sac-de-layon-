# Sac de Layon

Checklist de matériel pour les expéditions en Guyane : quantités recalculées selon la durée et le nombre de personnes, poids et volume du sac, matériel mémorisé d'une sortie à l'autre.

L'appli s'installe sur l'écran d'accueil du téléphone et fonctionne hors ligne. Les listes restent sur le téléphone de chacun.
